# Support

For ordinary setup/packaging bugs, use the issue tracker of the actual published
repository, or the existing project contact `support@mourn.bio` after confirming
it is current. No support SLA or platform-coverage guarantee has been verified.

Include the app version, OS/desktop environment, installation format, architecture,
and minimal reproduction steps. For Flatpak, include runtime/SDK commits and
redacted builder logs. State whether the failure occurs in an isolated test profile.

Do not attach `.env` files, HAR/cookie captures, passwords, keyring exports,
IndexedDB/SQLite dumps, decrypted chat logs, signing keys, or production account
identifiers. Review screenshots and logs before sharing. Security reports belong
in the private reporting process in [SECURITY.md](SECURITY.md).
